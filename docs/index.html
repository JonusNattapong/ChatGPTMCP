The Four Pillar Subsystems

Architected for separation of concerns, zero-config discovery, and bounded safety invariants.

💻

System & Machine

apps/server

Low-level operating system primitives, background process manager, verified git commits, and stateful persistent Python execution.

  • Verified Git Commits & Rollbacks
  • Persistent IPython Kernel (toolpy)
  • Process Supervisor & Circuit Breaker
  • Deterministic Contract Fingerprinting
🧠

ThinkForge

packages/thinkforge

Cognitive scaffolds enabling divergent, convergent, and stress-tested reasoning before writing code or making critical decisions.

  • Hypothesis Divergence & Reframing
  • Perspective Swapping & Devil's Advocate
  • System Boundary Stress-Testing
  • Contract Convergence Synthesizer
📚

Skill Hub

packages/skill-hub

Dynamic execution gateway for 111+ battle-tested agent procedures spanning security, architecture, frontend, devops, and marketing.

  • 111+ Curated Markdown Skills
  • Lightweight Descriptors & On-Demand Run
  • Safe Parameter Validation via Zod
  • Structured Result Envelope
💾

Living Memory Book

packages/memory

Pure Markdown second brain organized into Chapters, Subtopics, and Timesteps. Zero native C++ or SQLite dependencies.

  • Auto-Indexed Master Table of Contents (TOC)
  • Temporal Recall by Timestep (YYYY-MM-DD)
  • Self-Seeding from Bundled Snapshots
  • Full-Text Markdown Brain Search

Quick Start

Get up and running with ChatGPT Pilot in under two minutes.

1

Clone & Install

Clone the repository and install all workspace dependencies via pnpm.

git clone https://github.com/JonusNattapong/chatgpt-pilot.git
cd chatgpt-pilot
pnpm install
2

Build & Verify

Compile all workspace packages and run the verified test suite.

pnpm build
pnpm verify
3

Start Hybrid Gateway

Launch the server with the hybrid capability surface connecting all 4 pillars.

# Windows:
.\scripts\start-hybrid.ps1

# Linux/macOS:
./scripts/start-hybrid.sh
