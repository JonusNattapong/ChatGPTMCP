Technical reference

ChatGPTMCP Hybrid

ผิวเครื่องมือแบบกระชับสำหรับ ChatGPT ครอบ machine operations, reasoning tools, reusable skills และ persistent memory โดย ChatGPT วางแผนงาน ส่วน toolpy ใช้ประกอบ capability ที่อยู่ด้านล่าง

Public surface
2 tools
Runtime
Persistent IPython
Capability groups
coding / think / skills / memory
Transport
MCP over stdio or HTTP

Hybrid surface

Legacy mode เปิด low-level MCP tools ให้ ChatGPT เห็นโดยตรง ส่วน Hybrid mode เก็บ capability เหล่านั้นไว้หลัง controlled Python runtime แล้วเปิดต่อ ChatGPT เพียง toolpy และ capability_registry วิธีนี้ลด noise ตอนเลือก tool แต่ยังใช้ capability เดิมได้ครบผ่าน runtime

Public toolหน้าที่
toolpyรัน Python ที่โมเดลสร้างใน persistent controlled runtime ภายใน cell สามารถดู catalog, เรียก capability ที่ได้รับอนุญาต, รวมหลาย operation และคืน structured result ได้
capability_registryดู metadata ของ capability ที่อยู่หลัง toolpy แบ่งเป็น coding, think, skills และ memory โดยไม่ execute capability

Runtime contract

allow_tools

Read-only capabilities ใช้ได้เป็นค่าเริ่มต้น ส่วน capability ที่แก้ระบบต้องระบุอย่างชัดเจนบนคำขอ toolpy ชั้นนอก

session_id

กำหนด persistent IPython namespace ตัวแปร import และ helper ที่สร้างไว้สามารถอยู่ข้าม call ได้จนกว่าจะ reset, ถูก evict, worker restart หรือ timeout

max_calls

จำกัดจำนวน nested MCP capability calls ต่อหนึ่ง cell

timeout_ms

จำกัดเวลารัน cell เมื่อ timeout session จะถูก terminate เพื่อรับประกัน cleanup

max_output_bytes

จำกัด stdout, stderr, display output และ structured result

catalog = await describe()
status = await tools.machine_status({})
result({"catalog": catalog, "status": status})

Authority requirement: Hybrid mode ต้องใช้ --dangerously-open-machine เพราะ persistent Python runtime รันด้วยสิทธิ์ OS ของ MCP worker ถ้าต้องการ workspace-only authority ให้ใช้ bounded tool surface ปกติ หรือครอบ bridge ด้วย external sandbox

ต่อ provider เพิ่ม

Hybrid mode สามารถต่อ local provider directories ไว้หลัง toolpy ปัจจุบัน CLI รองรับ Skill Hub, ThinkForge และ OurBook memory

node dist/index.js \
  --dangerously-open-machine \
  --tool-surface hybrid \
  --skill-hub-dir D:\Projects\Github\chatgpt-skill-hub \
  --thinkforge-dir D:\Projects\Github\ThinkForge-MCP \
  --memory-dir D:\Projects\Github\ourbook

สถาปัตยกรรม

Streamable HTTP เข้า MCP server โดยตรง ส่วน tunnel stdio ผ่าน src/supervisor.ts ซึ่งแยก src/index.ts ไปอยู่ worker process และ restart พร้อม reinitialize worker ได้เมื่อ crash หรือชน hard request deadline ภายใน worker registry จะ validate ชื่อ tool และ arguments ก่อนผ่าน policy, preconditions, idempotency และ handler ที่แตะ host จริง

Tunnel เป็น transport plumbing เท่านั้น MCP server ไม่ได้ผูกกับ ChatGPT UI ตัวใดตัวหนึ่ง และใช้กับ MCP client ที่รองรับ protocol เดียวกันได้

Tool surface

ใน Legacy mode server เปิด purpose-built tools สำหรับงาน host โดยตรง ส่วน Hybrid mode เก็บ capability เดิมไว้เรียกผ่าน toolpy โดยไม่โฆษณาทุกตัวให้ ChatGPT เห็นพร้อมกัน

Inspect

machine_status, file reads, project snapshot, directory listing, file discovery, metadata, image inspection และ code search

Edit

write, targeted edit, transactional update และ patch application

Run

shell execution และ managed process lifecycle ทั้ง start, status, output, wait, stop และ stdin

Git

status, diff, log, show, branch, add, commit, verified commit, checkout และ push โดยไม่ใช้ shell interpolation

System

process, port, environment, disk, network และ machine inspection แบบ bounded พร้อม redaction

Workflow

verification gates, idempotency, audit, remote-machine routing และ optional bounded OSINT

Concurrency guard

File read คืน SHA-256 digest และ write สามารถส่ง expected_sha256 ได้ ถ้าไฟล์เปลี่ยนหลังจากอ่าน ระบบจะคืน PRECONDITION_FAILED แทนการเขียนทับแบบเงียบ ๆ

Stable failures

Codeความหมาย
INVALID_ARGUMENTInput ขาด, ไม่ถูกต้อง หรือเกินขอบเขต
PATH_DENIEDติด workspace boundary, symlink escape หรือ OS permission
PRECONDITION_FAILEDไฟล์เปลี่ยนหลังจากถูกอ่าน
AMBIGUOUS_MATCH / NO_MATCHText edit ไม่สามารถ apply ได้อย่างปลอดภัย
TIMEOUT / NETWORKCommand หรือ network operation ไม่เสร็จตามเงื่อนไข

Safety model

Workspace-only mode บังคับ file tools, search, shell working directories และ patches ให้อยู่ใต้ --root พร้อมปฏิเสธ symlink และ junction escape

Unrestricted mode ใช้ --dangerously-open-machine เพื่อเปิด absolute paths และ shell reach ตามสิทธิ์ของ OS account ปัจจุบัน Hybrid mode ต้องใช้ authority แบบนี้เพราะพึ่ง persistent Python runtime

นี่คือ administrative bridge ไม่ใช่ hostile multi-tenant sandbox ให้ต่อเฉพาะ client และ tunnel ที่ไว้ใจได้ในระดับเดียวกับ OS account ที่รัน server

Transport

ใช้ supervised stdio สำหรับ tunnel หรือ Streamable HTTP เป็น transport ทางเลือก

node dist/index.js --http --http-port 8787 --root D:\Projects\Github

/healthz รายงาน liveness, /readyz รายงาน readiness, MCP traffic อยู่ที่ /mcp และหน้า /ui อ่าน redacted audit events จาก /ui/audit

ถ้า bind HTTP ออกนอก loopback ต้องกำหนด bearer token ซึ่งจะใช้ป้องกัน UI endpoints ด้วย

Operations

สำหรับ server และ watcher ให้ใช้ managed process runtime โดย metadata และ bounded logs จะเก็บใต้ .chatgpt-machine/ ทำให้ MCP worker ที่ restart แล้วยัง recover การ inspect และ stop process ได้

Local runtime settings อยู่ใน Git-ignored .chatgpt-machine/config.json และ chatgpt-local use <path> ใช้บันทึก active workspace

Multi-machine gateway

Allowlisted Streamable HTTP nodes เก็บใน Git-ignored .chatgpt-machine/machines.json ตัว selector รองรับ id, name, hostname, alias, IP address หรือ host:port แต่ไม่รับ arbitrary URL จาก tool caller
